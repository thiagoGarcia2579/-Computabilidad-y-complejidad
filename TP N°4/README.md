## Funciones Calculables

Una función se considera calculable si existe una Máquina de Turing capaz de obtener su resultado para cualquier entrada válida, siguiendo un conjunto finito y definido de reglas. El estudio de las funciones calculables permite analizar qué problemas pueden ser resueltos mediante algoritmos y cuáles quedan fuera de los límites de la computación.
