## Máquina de Turing Universal

Una Máquina de Turing Universal (MTU) es una Máquina de Turing capaz de simular el comportamiento de cualquier otra Máquina de Turing. Para ello, recibe como entrada la descripción de una máquina junto con los datos sobre los que esta debe operar. Este concepto constituye una base fundamental de la computación universal, ya que permite que una única máquina pueda ejecutar distintos algoritmos.
